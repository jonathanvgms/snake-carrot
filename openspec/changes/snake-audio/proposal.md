## Why

Agregar efectos de sonido y música de fondo al juego Snake para mejorar la experiencia del usuario y hacer el juego más inmersivo y entretenido.

## What Changes

- Música de fondo tipo loop que suena mientras el juego está activo
- Efecto de sonido al comer una zanahoria
- Efecto de sonido al subir de nivel
- Efecto de sonido al morir (Game Over)
- Sonidos generados con Web Audio API (sin archivos externos)

## Capabilities

### New Capabilities
- **snake-audio**: Sistema de audio con música de fondo y efectos sonoros generados con Web Audio API
